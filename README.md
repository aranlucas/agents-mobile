Expo client for travel, grocery, fitness, and wellness workflows served by the Go [Agents gateway](https://github.com/aranlucas/agents). Each tab pairs a conversation with a summary of the agent's state. Proposed work and acceptance criteria are in [ROADMAP.md](ROADMAP.md).

## Configure the app

Use the Node.js version in [`.node-version`](.node-version) and pnpm version in [`package.json`](package.json). Android builds need an Android SDK with `ANDROID_HOME` set ([Expo setup](https://docs.expo.dev/get-started/set-up-your-environment/?platform=android&device=physical&mode=development-build&buildEnv=local)); local iOS builds need macOS and Xcode.

```sh
pnpm install
cp .env.example .env.local
```

Replace the placeholders from [`.env.example`](.env.example) with your Clerk publishable key and gateway's CopilotKit runtime base URL. The gateway must accept tokens from that Clerk instance. Leave the Sentry DSN empty to disable client error reporting.

Launch a native development build, or run the web client:

```sh
pnpm android
pnpm ios
pnpm web
```

`pnpm web` uses [Portless](https://github.com/vercel-labs/portless) at https://agents-mobile.localhost in the main checkout; linked worktrees get a branch subdomain. Its first run may ask for `sudo` to bind port 443 and trust a local certificate.

On Android, gateway URLs beginning with `http://localhost` or `http://127.0.0.1` are rewritten to the emulator host `10.0.2.2`. For a physical device, use a gateway address reachable from the device.

Native projects are generated by Expo and are not committed. Rebuild the development client after changing native dependencies or the Expo SDK; use `pnpm start` for subsequent JavaScript development.

## Validation

```sh
pnpm check && pnpm test
```

EAS build profiles are in [`eas.json`](eas.json).

Husky’s `pre-push` hook runs Expo’s SDK-compatible dependency alignment. If Expo
updates `package.json` or `pnpm-lock.yaml`, the push stops so you can review and
commit both files, then push again. Existing staged or unstaged dependency edits
are left untouched; commit or stash them before pushing. Network or resolver
failures also block the push.
