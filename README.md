Take your travel plans, grocery list, fitness routine, and wellness check-in with you. Agents Mobile is the Expo client for four workflows served by the Go [Agents gateway](https://github.com/aranlucas/agents). Each tab pairs an agent conversation with a compact view of the state it produces.

## Ask, plan, and keep moving

Sign in with Clerk, tell an agent what you need, and refine the result in chat. The app refreshes your Clerk session token before each agent run.

```text
Travel   → Turn a few ideas into a trip plan.
Grocery  → Plan meals and organize the shop.
Fitness  → Build a training plan around your goals and routine.
Wellness → Coordinate a wellness plan with the agent.
```

## Configure the app

Requirements: Node.js from `.node-version`, pnpm from `package.json`. Android builds need an Android SDK with `ANDROID_HOME` set ([Expo setup](https://docs.expo.dev/get-started/set-up-your-environment/?platform=android&device=physical&mode=development-build&buildEnv=local)); local iOS builds need macOS and Xcode.

```sh
pnpm install
cp .env.example .env.local
```

Set these values in `.env.local`:

| Variable                             | Use                                              |
| ------------------------------------ | ------------------------------------------------ |
| `EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY`  | Clerk sign-in.                                   |
| `EXPO_PUBLIC_COPILOTKIT_RUNTIME_URL` | CopilotKit runtime URL hosted by the Go gateway. |
| `EXPO_PUBLIC_SENTRY_DSN`             | Optional client error reporting.                 |

Start the Expo server or launch a native development build:

```sh
pnpm start
pnpm android
pnpm ios
pnpm web
```

`pnpm web` serves the web build at https://agents-mobile.localhost through [Portless](https://github.com/vercel-labs/portless) (a dev dependency); its first run may ask for `sudo` to bind port 443 and trust a local certificate.

When using an Android emulator, local gateway URLs are rewritten to the emulator host `10.0.2.2`.

After upgrading to Expo SDK 58, rebuild your development client with `pnpm android` or `pnpm ios`; an SDK 57 client cannot load the upgraded app. Native projects are generated by Expo prebuild and are not committed. SDK 58 keeps this app's `web.output: "server"` setting, which now renders HTML on each request.

The app is a single package. `pnpm-workspace.yaml` contains only pnpm 12 dependency and build settings; app contracts live in `src/types/`.

## Peek under the hood

- `src/app/` contains the Travel, Grocery, Fitness, and Wellness routes.
- `src/components/agent-screen.tsx` and `src/components/app-tabs.tsx` provide shared agent screens and navigation.
- `src/native-markdown/` contains the app's local chat Markdown renderer.
- `src/types/` defines the app's gateway contracts.

```sh
pnpm lint
pnpm fmt:check
pnpm typecheck
pnpm test
```
